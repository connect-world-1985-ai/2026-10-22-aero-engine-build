# Stylized CFM LEAP-1A turbofan — procedural Blender build

Built 2026-10-22/23 (Asia/Shanghai) for Raymond Shen. Everything is generated by `engine.py` with bpy. No downloaded models, textures or HDRIs, and no text in any image.

## Deliverables
| File | What |
|---|---|
| `engine.py` | the whole model, materials, studio, cameras and render settings |
| `engine.blend` | editable file with two scenes, **Cutaway** and **Exterior**. Modifiers are not applied and every part has its own collection |
| `renders/cutaway.png` | 1920x1080, 110° wedge cutaway, Cycles CPU |
| `renders/exterior.png` | 1920x1080, front three-quarter product shot, Cycles CPU |
| `previews/` | side proportion check, iteration previews, mid-quality checks |
| `logs/` | Blender logs, render times, checkpoint notes, secret scan |

## Run (Blender 4.3.2, headless)
```
B=/workspace/tools/blender-4.3.2-linux-x64/blender
$B -b -P engine.py -- side                 # orthographic half-section with reference bars -> previews/side.png
$B -b -P engine.py -- preview cut|ext      # 640x360, 16 samples
$B -b -P engine.py -- mid cut|ext          # 1280x720, 64 samples
$B -b -P engine.py -- still cut|ext        # 1920x1080, 256 samples adaptive (thr 0.015) -> renders/
$B -b -P engine.py -- setup                # saves engine.blend
```
Options are passed as `key=value`: `samples=`, `tag=`, `span=` (wedge angle in degrees, default 110), `center=` (wedge centre, default 135° = top-left as seen from the camera), `pylon=1` (render the P2 pylon stub on the exterior), and `cx= cy= cz= lens=` (cutaway camera).
In `engine.blend`, switch scenes to change views. Shell parts (nacelle, bypass duct walls, core cowl, nozzle, plug) exist as `*_360` and `*_cut` child collections, and each scene's view layer excludes the version it doesn't use. To change blade counts or the wedge angle, edit the constants in `engine.py` and re-run `setup`. The blade rows are baked meshes (see Deviations).

## What was cut
Nothing from P0 or P1. From P2, the bearing rings and the spinner spiral are in. The pylon stub is built (`12_Pylon_ext`) but **left out of the exterior render** because it read as a flat board; render it with `pylon=1`, or un-exclude the collection in the Exterior view layer.

## Deviations from the plan, and why
1. **LEAP-1A stage counts, not the CFM56-7B mix** (Raymond's decision): 18 fan blades, 3 LPC (with 4 stator rows), 10 HPC (IGV + 9 stators), 2 HPT, 7 LPT, 19 fuel nozzles. The overall scale comes from the 78 in fan and the 3.328 m flange length.
2. **Blade rows are baked meshes, not Array modifiers.** An Array modifier can't skip the blades inside the cut wedge, so every row is generated per blade with the wedge filter applied. To change counts, edit `engine.py` and re-run `setup`.
3. **Wedge is 110°, not 90°.** At 90° the booster was hidden behind the fan ring. The full ring of fan blades is kept.
4. **Cutaway camera is above and slightly behind the fan plane** rather than a classic front three-quarter view. From in front, the full fan ring hides the LPC; the front of the fan is shown in the exterior image instead.
5. **Output folder** is `/workspace/2026-10-22-aero-engine-build/` as Martin specified, not the plan's `...-aero-engine-blender`.
6. **The EEVEE probe from step 0 was skipped.** Cycles previews took about 4 s, so a faster check wasn't needed.
7. **Compositor** keeps only a gentle vignette. The demo's bloom and streaks were dropped for the product-photography look.
8. Render metadata stamps (`use_stamp_*`) are off as well as the burn-in, so the PNGs carry no file path, date or hostname. Cycles still writes its sample and time keys.
9. **Bug fixed after the finals:** each scene's compositor Render Layers node defaulted to the scene that was active when the script ran, so in the saved .blend the Exterior scene rendered the Cutaway scene. `rl.scene` is now set explicitly. Both finals were rendered with their own scene active, so they were not affected. Both scenes in the re-saved `engine.blend` were verified (previews/blendcheck_v3.png, and again after the colour tweak: previews/blendcheck_tweak.png).

## Verification done
- `previews/side_final.png`: in this orthographic half-section the reference bars sit at x=0 and x=3.328 m and at r=±0.991 m. Measured in the image: 608 px for 3.328 m and 364 px for 1.99 m, which matches the length-to-fan-diameter ratio of 1.68.
- Both finals are 1920x1080 RGB, with no text objects (the script asserts this), no burned-in stamp and no metadata stamp.
- `engine.blend` opens headless, and both scenes render (`-S Exterior` and `-S Cutaway`).

## Colour tweak (2026-10-23, Asia/Shanghai)
Requested after review: the section caps read salmon and the fan blades read light grey. `CutFace_Coral` became `CutFace_DeepRed`, with linear base colour (0.075, 0.0012, 0.001), roughness 0.70, specular 0.1 and no emission; it renders at about sRGB #8C2621 to #A10702 under the cutaway lights. `Fan_Composite` is now non-metallic with no coat, linear base colour (0.007, 0.0085, 0.010), roughness 0.55, specular 0.12 and sheen 0.05; it renders charcoal, about sRGB #23272A to #2E3235, in the cutaway and near-black in the exterior. Geometry, lights, cameras and render settings are unchanged.
