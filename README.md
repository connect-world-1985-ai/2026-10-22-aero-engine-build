# Stylized CFM LEAP-1A turbofan — procedural Blender build

Built 2026-10-22/23 (Asia/Shanghai) for Raymond Shen. Everything is generated by `engine.py` with bpy. No downloaded models, textures or HDRIs, and no text in any image.

## Deliverables
| File | What |
|---|---|
| `engine.py` | the whole model, materials, studio, cameras and render settings |
| `engine.blend` | editable file with two scenes, **Cutaway** and **Exterior**. Modifiers are not applied and every part has its own collection |
| `renders/cutaway.png` | 1920x1080, 110° wedge cutaway, Cycles CPU |
| `renders/exterior.png` | 1920x1080, front three-quarter product shot, Cycles CPU |
| `previews/` | side proportion check, iteration previews, mid-quality checks |
| `logs/` | Blender logs, render times, checkpoint notes, secret scan |

## Run (Blender 4.3.2, headless)
```
B=/workspace/tools/blender-4.3.2-linux-x64/blender
$B -b -P engine.py -- side                 # orthographic half-section with reference bars -> previews/side.png
$B -b -P engine.py -- preview cut|ext      # 640x360, 16 samples
$B -b -P engine.py -- mid cut|ext          # 1280x720, 64 samples
$B -b -P engine.py -- still cut|ext        # 1920x1080, 256 samples adaptive (thr 0.015) -> renders/
$B -b -P engine.py -- setup                # saves engine.blend
```
Options are passed as `key=value`: `samples=`, `tag=`, `span=` (wedge angle in degrees, default 110), `center=` (wedge centre, default 135° = top-left as seen from the camera), `pylon=1` (render the P2 pylon stub on the exterior), and `cx= cy= cz= lens=` (cutaway camera).
In `engine.blend`, switch scenes to change views. Shell parts (nacelle, bypass duct walls, core cowl, nozzle, plug) exist as `*_360` and `*_cut` child collections, and each scene's view layer excludes the version it doesn't use. To change blade counts or the wedge angle, edit the constants in `engine.py` and re-run `setup`. The blade rows are baked meshes (see Deviations).

## LEAP-1A reference numbers (public sources only)
| Item | Value used | Source |
|---|---|---|
| Architecture | single-stage fan, 3-stage LPC, 10-stage HPC, annular combustor, 2-stage HPT, 7-stage LPT, dual rotor | EASA TCDS E.110 Issue 14 (11 May 2026), §2: https://www.easa.europa.eu/en/downloads/20086/en |
| Length | 3.328 m (fan case forward flange to turbine rear frame aft flange) | EASA TCDS E.110 §4. Also Japan CAB TADS No.778 |
| Max envelope | 2.543 m W x 2.368 m H (bare engine) | EASA TCDS E.110 §4 |
| Fan diameter | 78 in = 1.981 m | CFM https://www.cfmaeroengines.com/leap, Safran LEAP-1A product page |
| Fan blades | 18 (3D-woven RTM composite) | Airbus A320neo LEAP-1A technical training manual (ATA 70/72). Also AirInsight (citing CFM) and Wikipedia |
| Bypass ratio | 11:1 | same Airbus training manual, AirInsight |
| Fuel nozzles | 19 | Airbus training manual |
| Booster rows | 3 rotor + 4 stator | Airbus training manual |
| HPC stator rows | IGV + 4 variable + 5 fixed (modelled as IGV + 9) | Airbus training manual |

Stylized (no public number, chosen by eye): inlet lip length (-0.80 m), plug tip (4.0 m), nacelle max radius 1.16 m, every blade count other than the 18 fan blades and 19 nozzles, and all flow-path radii other than the fan tip.

## The 10 parts (collections in engine.blend)
01_Fan (spinner with spiral, 18 blades, disc), 02_LPC_Booster, 03_HPC, 04_Combustor (liner, glow, 19 nozzles), 05_HPT, 06_LPT, 07_Exhaust_Nozzle (core nozzle and plug), 08_Bypass_Duct (outer wall, core cowl, OGVs), 09_Nacelle, 10_Shafts_DualRotor (LP blue, HP copper). Also 11_Structure (core casing, fan hub frame, TCF, TRF, bearings) and 12_Pylon_ext.

## Colour key (no labels)
Nacelle: satin white paint. Bypass duct walls: satin aluminium. Fan: dark composite. LPC: warm titanium. HPC: bright steel. Stators and frames: dark steel/gunmetal. Combustor: Inconel bronze with an orange glow. HPT: dark gold. LPT: tempered blue. Exhaust: heat-tint dark grey. LP shaft: blue. HP shaft: copper. Cut faces: brick coral (light warm grey on nacelle/duct). Shaft cut faces use the shaft colour.
